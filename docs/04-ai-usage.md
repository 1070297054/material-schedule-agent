# AI 使用披露

## 本版本的真实分工

本项目由用户要求 AI 助手直接实现。**当前代码、测试、合成数据、说明文档与示例生成脚本主要由 Codex 编写和执行。** 用户提供了考核规范并授权实现，尚未记录用户亲自修改代码或运行验证的事实。

不能把本文件或其他文档中的实现取舍当作候选人已经独立完成的工作，也不能声称已经验证真实模型效果。候选人的个人贡献需要在亲自理解、修改和运行之后补充。

| 工作 | AI 使用范围 | 当前已验证的部分 |
| --- | --- | --- |
| 题目选择与设计 | 分析约束、选择第 1 题、设计单模型循环和事务边界 | 对照题目列出验收矩阵 |
| 工程实现 | 编写 Python CLI、工具、模型适配、SQLite 存储 | 自动化测试与离线运行 |
| 数据与案例 | 编写完全合成的素材、规则与排期 | 输入与输出在 examples 内可复现 |
| 测试与修复 | 编写业务/协议/CLI/并发测试，修正确认状态回退问题 | 实际日志见 examples/test-results.txt |
| 文档 | 生成需求、方案、评估与复盘初稿 | 与当前代码及实际结果对应 |
| 接口核对 | 查阅 OpenAI 官方 Function calling 文档 | 协议替身测试；未调用真实模型 |

## 本次 AI 辅助交互摘要

1. 用户提供四道考核题与统一交付要求，询问选题。
2. AI 建议素材审核与排期，强调确认边界、去重及动态工具决策。
3. 用户授权直接实现项目。
4. AI 在空仓库实现代码和文档，运行测试，生成离线验收证据。

没有使用子 Agent。没有把 ChatGPT/Codex 会话本身当作此项目真实 API 调用证据，没有读取用户登录令牌来替代项目 API 密钥。

## 候选人提交前需要如实补充

| 记录项 | 当前状态 |
| --- | --- |
| 候选人亲自实现/修改的模块 | 待实际完成后填写 |
| 修改前后的问题与行为变化 | 待实际完成后填写 |
| 候选人独立运行的命令、结果、日期 | 待实际完成后填写 |
| 候选人能够解释的技术取舍 | 需自行复核；不得默认已经掌握 |
| 实际个人投入时间 | 未记录，不能用 AI 执行时间替代 |
| 真实模型名称、运行记录、失败分析 | 尚未运行 |

建议亲自尝试一次有意义的变更，例如增加“同一平台两次发布至少间隔一小时”的业务规则，并用改变占用数据前后的真实模型记录验证影响。只有实际完成后，才把该工作写为个人贡献。
